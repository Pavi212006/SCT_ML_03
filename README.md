
## 🐱🐶 Task 03: Image Classification (Supervised Learning)

### 📌 Project Overview
This project involves building a **Support Vector Machine (SVM)** to classify images into two categories: **Cats** and **Dogs**. The model focuses on binary classification using high-dimensional feature vectors to represent image pixel data.

### 🚀 Key Features
- **SVM Implementation:** Utilized a **Linear Kernel** to effectively separate image features in a multi-dimensional space.
- **Feature Extraction:** Simulated image texture and edge features to demonstrate the model's classification logic.
- **Performance Evaluation:** Includes an automated accuracy scoring system and visualization of the model's confidence levels.
- **Scalable Logic:** The architecture is designed to handle larger datasets like the Kaggle Cats vs. Dogs collection.

### 🛠️ Tech Stack
- **Language:** Python 3.10
- **Algorithm:** Support Vector Machine (Scikit-Learn)
- **Visualization:** Matplotlib (Accuracy Metrics)
- **Numerical Processing:** NumPy & Pandas

### 📊 How to Run
  Run the script:
   python SCT_03.py
